# Hubera — ce dépôt

Ce dossier Git (`PavelDelhomme/Cloudity`) **garde son nom** : c’est le code live Mail / Drive / Pass / suite, servi par la stack Portainer **`cloudity`**.

Ne pas renommer le répertoire, la stack, les volumes, ni les `applicationId` (`fr.cloudity.*`, `com.cloudity.*`, `cloud.hubera.*`).

Marque produit : **Hubera**. Docs : https://docs.hubera.cloud

Les packages Dart `cloudity_shared` / `cloudity_auth_broker` gardent ce nom (imports + broker Android). L’UI affiche Hubera.
